## What can be transferred

The converter aims to carry over:

* Player name, location, playtime, and watch rank
* Inventory, equipment, and key items
* Owned Yo-kai and their nicknames
* Party and formation
* Story progress and current objectives
* World and event progress
* Records, settings, and other compatible save data

Information that exists only in the Nintendo Switch version is preserved where possible. Data used only by the Nintendo 3DS version is not transferred.

## How to use it

1. Back up your original save files.
2. Open the converter using the link above.
3. Select your Yo-kai Watch 1 Nintendo 3DS save.
4. Convert and download the new Nintendo Switch save.
5. Move the save onto your emulator/cfw switch.

## Important information

This converter is experimental, so some information may not transfer perfectly. The **Requests Completed** record is a known issue that still needs to be fixed.
